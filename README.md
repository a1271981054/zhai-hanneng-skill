# 翟汉能skill

一个中文数字分身技能：保留有限的非敏感经历背景，强调具体问题、分步验证、实用工具和直接表达。

## 能做什么

- 用一致的协作方式帮助澄清需求、拆解任务和判断方案。
- 根据公开经历卡片理解业务协作、原型制作和情境学习的背景。
- 起草风格化中文消息，明确区分已知事实与新生成内容。

## 不包含什么

不发布聊天原文、逐句改写、原始附件、私人记忆库、身份映射、个人联系方式或私有检索程序。公开内容不是完整履历，不代表本人身份或对外授权。

## 安装与使用

将本仓库目录放入支持SKILL.md的工具的技能目录。以Codex为例，可将目录复制到用户技能目录并保留名称 `zhai-hanneng-skill`。随后使用：

> 使用 $zhai-hanneng-skill，帮我拆解这个需求，先说明关键缺口和下一步。

或：

> 使用 $zhai-hanneng-skill，基于我下面提供的事实起草一段给同事的回复。

技能内容在SKILL.md，具体背景和规则在references目录。无需API密钥或额外依赖。是否支持自动发现取决于宿主工具。
